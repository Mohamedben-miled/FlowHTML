# Flow Coworking Space Website

Welcome to the official repository of **Flow Coworking Space**, a modern and dynamic coworking hub based in Soukra, Tunisia. This project is a clean, responsive, and user-friendly website designed to promote Flow’s services and engage with the professional community.

## 🌟 Features

- ✅ Responsive design with modern UI
- ✅ Section-based layout: Home, Features, Pricing, Gallery, Community
- ✅ Booking and subscription calls-to-action
- ✅ SEO-friendly meta tags (description, keywords)
- ✅ Social sharing support via Open Graph & Twitter Cards
- ✅ Modern styling using Bootstrap 5 and Font Awesome icons

## 🔧 Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- Font Awesome
- JavaScript (optional, for future enhancements)
